# DUMJ BYZ

Projektunterlagen des Instagram-KI-Projekts DUMJ BYZ (drei faceless Kanäle: Rolling Nowhere, Slow Seasons, Deep Calm).

## Ordnerstruktur

```
workspace/   Tabs des Workspace-Docs "DUMJ BYZ Workspace" als Markdown
  1_Start-hier.md        Überblick, Zuständigkeiten, To-dos, Update-Log
  2_Regeln-und-Plan.md   Grundregeln, Ablauf pro Video, Posting-Zeiten, Testphase
  3_Rolling-Nowhere.md   Kanal-Tab POV-Fahrten
  4_Slow-Seasons.md      Kanal-Tab Herbst/Winter
  5_Deep-Calm.md         Kanal-Tab Unterwasser
  6_Credits.md           Kling-Budget und Verbrauch
  7_Auswertung.md        Kennzahlen und Kanal-Vergleich
cockpit/     Unterlagen für das DUMJ BYZ Cockpit (Artifact)
  cockpit-anleitung.md       Funktionen und Einrichtung
  dumj-byz-cockpit.html      Cockpit-Quelle
  kanaele-startdaten.json    Startdaten der drei Kanäle
archiv/      Pausierte und verworfene Kanäle
  avatar-kanaele/            Herberts Trippin und Olli on Olympus (Prompts, Bilder, Skripte, Stand 1.10.)
  weitere-kanal-ideen.md     Bernhart Beacht, Bill Keeper, Fog Archive, Peters Precast, Sammy Seastar
```
